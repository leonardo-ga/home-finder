# Application architecture

Home Finder is a read-only Angular catalogue with a Leaflet map. Its data is bundled with the application. There is no backend or browser persistence.

## Source layout

```text
src/app/
  app.component.ts                         Application shell
  features/homes/
    domain/
      home.catalogue.ts                    Sole catalogue data source
      home.model.ts                        Read-only property model
      home.validation.ts                   Catalogue checks
      home.costs.ts                        Known recurring and initial cost calculations
      home.sort.ts                         Stable, non-mutating catalogue ordering
    state/
      homes.store.ts                       Catalogue access and temporary selection
    pages/
      homes-page.component.*               Catalogue and map composition
    components/
      home-card/                           Property summary and selection
      home-map/                            Leaflet lifecycle and markers
      home-details/                        Selected property and original listing link
  shared/
    money.ts                               Currency formatting
```

Component styles live beside their components. `src/styles.css` contains shared tokens and primitives. `src/styles/map-markers.css` styles markup generated by Leaflet.

## Catalogue ownership

`home.catalogue.ts` is the only source of homes. The `Home` interface declares every field read-only, and both the exported array and its records are frozen at runtime. There are no add, edit, delete, import, export, or save operations.

To change the catalogue:

1. Edit the records in `src/app/features/homes/domain/home.catalogue.ts`.
2. Verify property details against the original listing and update `documentation/listings.md` where appropriate.
3. Run the checks, build locally, commit the source and generated `docs/` output, and deploy through GitHub Pages.

Every visitor sees the catalogue included in the deployed application. Previously saved IndexedDB data is not read, changed, or deleted by this version and cannot override the catalogue. No storage migration is needed. The app does not access IndexedDB, local storage, or session storage.

## State and data flow

```text
Source catalogue -> HomesStore -> card inputs and map pins
Card/pin selection -> HomesStore selection signal -> selected card and map pin
Più dettagli -> page modal selection -> separate property details dialog
```

The store exposes the catalogue synchronously. Its mutable state is limited to the selected home ID and list ordering. Sorting uses a computed projection of the immutable catalogue; the map continues receiving the original records. Rankings use monthly rent plus fees, rent-only cost per m², area, or known deposits. Unknown deposits are placed last and ties preserve catalogue order. Changing order resets the list scroll position but retains selection. Selection remains in memory, is scoped to the page instance, and resets when the page reloads. Unknown IDs are ignored. Selecting a map pin scrolls its card into view, shows a selection badge, and announces the result to assistive technology. Scrolling respects reduced-motion preferences. Each card has a native map-selection button stretched over its surface and a separate details button above it. The buttons are siblings, so details clicks cannot bubble into map selection. The details button spans the card width and has a minimum 44px height. The page separately tracks the home shown in the details modal. Closing the modal leaves map selection intact.

Property details use a native HTML dialog outside the map. It supplies modal focus containment and keyboard dismissal. Closing the dialog restores browser focus; its lifecycle also locks and restores background scrolling. Details can be closed with the close button, Escape, or a backdrop click.

The known monthly cost is rent plus condominium fees. The deposit is optional and remains unknown when not published. The modal lists the deposit once, separately from recurring charges; it does not calculate a combined initial payment. The cost per square metre uses rent only. None of these derived values is separately persisted.

The page composes the interface. Components receive typed inputs and emit selection/close events; they do not mutate the catalogue. All application components use `OnPush` change detection, and list rendering tracks stable property IDs.

The map owns its Leaflet instance, markers, and resize observer. It runs map activity outside Angular's zone, emits selection events inside the zone, and releases its resources on destruction. It uses the positions recorded in the catalogue; it does not geocode addresses at runtime.

## Build and deployment

`npm run build` writes the production application directly into `docs/`, with `docs/index.html` as its entry point. The production base path is `/home-finder/`. The build copies `public/.nojekyll` into the output. Development uses `/` and does not replace the committed deployment output.

Publish using **GitHub Pages → Deploy from a branch → main → /docs**. Build locally, commit the complete generated directory with the source changes, and push. No custom Actions workflow or backend is required. Project documentation lives in `documentation/`; `docs/` is reserved for generated files.

See the [deployment procedure](../README.md#deploy-to-github-pages) and [catalogue sources](listings.md).

## Verification

```sh
npm test
npm exec -- ngc --project tsconfig.json --noEmit
npm run format:check
```

Tests check catalogue records, immutable data, selection behavior, and operation without browser storage APIs. The Angular compiler checks templates without creating a production build. Tests use Angular's actual signal implementation and Node's built-in test runner. Its Node 18 module-resolution flag emits an experimental warning.

## Future changes

Add editing, persistence, filters, or commute calculations only when required. Each would introduce new behavior and should have an explicit data/state boundary. In particular, adding a browser editor must not silently replace the source-controlled catalogue as the source of truth.
